# Azazel Trader

Автономный терминал анализа криптопортфеля: Telegram-бот, Mini App и движок автономного цикла.

## Структура

| Файл | Назначение |
|---|---|
| `azazel_config.json` | **Статический профиль**: 14 скилов с расписанием, параметры алгоритма, стратегии A/B/C, кошельки, цены. Источник правды для интерфейса и бота. |
| `autotrading_config.json` | **Runtime-состояние**: баланс, открытые позиции, снапшот рынка, алерты. Перезаписывается по мере торговли. |
| `trading_algorithm_v5.md` | Алгоритм v5.2 — 20+ правил: сигналы, мани-менеджмент, фильтры. |
| `trading_algorithm.md` | Предыдущая версия алгоритма, для сверки. |
| `continuation_engine.py` | Движок автономного цикла. |
| `scalping_framework_v2.py` | Фреймворк скальпинга. |
| `scalping_strategies.py` | Реализация стратегий. |
| `design-system/tokens.json` | Дизайн-токены интерфейса. |

`azazel_config.json` и `autotrading_config.json` — разные артефакты, смешивать их нельзя: профиль меняется только при правке правил, runtime обновляется постоянно.

## Mini App

https://azazel-trader-yz2uw75a.agent.mira.tg

Интерфейс: Портфель → Рынок → Монитор → Сделки → Алгоритм → Терминал. Конфиг в странице продублирован статикой; для единого источника правды фронтенд должен читать `azazel_config.json` с `raw.githubusercontent.com`.

## Автономный цикл

Движок написан, но на сервере не развёрнут: бот собирает параметры и пишет их в Airtable. Пока цикл не подключён, приложение показывает правила и фактические цифры сделок, но само позиции не открывает.
